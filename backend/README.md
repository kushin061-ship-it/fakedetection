# Fake Review Detection — Backend Service

Enterprise-grade FastAPI backend and machine learning pipeline for deceptive review detection, TreeSHAP feature attribution, and association pattern mining.

---

## 1. Quickstart

### Environment Setup
Activate the virtual environment:
```powershell
# Windows PowerShell
.\backend\.venv\Scripts\Activate.ps1
```

### Running the API Server
Start the FastAPI server on port 8000:
```powershell
# From the backend directory
cd backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
# Or directly:
python -m app.main
```
- Interactive API Docs (Swagger UI): [http://localhost:8000/docs](http://localhost:8000/docs)
- Alternative Docs (ReDoc): [http://localhost:8000/redoc](http://localhost:8000/redoc)
- Health Probe: [http://localhost:8000/health](http://localhost:8000/health)

## 3. Endpoints & Frontend Contract

All endpoints match the contract defined in `frontend/src/api/README.md`:

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | System health and artifact loading probe |
| `GET` | `/api/eda` | Exploratory data analysis metrics, class balance, rating distributions, and monthly spikes |
| `POST` | `/api/predict` | Single review inference: fake probability, classification, top 10 SHAP features, and legal disclaimer |
| `POST` | `/api/predict/batch` | Bulk review inference via multipart CSV or JSON file upload (up to 10 MB) |
| `GET` | `/api/models/compare` | Model comparison leaderboard (F1, ROC-AUC, 20-point ROC curves) across 5 classifiers |
| `GET` | `/api/models/confusion/{model}` | Detailed confusion matrix for a specific model (`xgboost`, `lightgbm`, `random_forest`, `logistic_regression`, `naive_bayes`) |
| `GET` | `/api/errors` | Paginated and searchable false positives, false negatives, and low-confidence test cases |
| `GET` | `/api/explain/global` | Global TreeSHAP feature importances across Textual, Behavioral, and Temporal groups |
| `GET` | `/api/patterns` | Data-mined association rules (FP-Growth/Apriori) and flagged syndicate accounts |
| `GET` | `/api/reviewer/{id}` | Reviewer profile, lifetime statistics, and chronological timeline |

## 4. End-to-End ML Pipeline

The backend strictly decouples model training from API serving. The API **never trains models at request time** and only loads serialized artifacts (`.joblib` and `.json`) generated by the pipeline runner.

To retrain models and regenerate artifacts:
```powershell
# Run full pipeline
python -m ml.run_pipeline

# Quick run with subsample
python -m ml.run_pipeline --sample 5000
```

### Pipeline Phases
1. **Synthetic Data Generation**: Generates 20,000 realistic reviews with authentic burst injection and fraud patterns if raw data is absent.
2. **Preprocessing & Stratified Split**: Stratified 70% Train, 15% Validation, 15% Test split with text normalization.
3. **Exploratory Data Analysis**: Computes rating distributions, review length histograms, reviewer activity bins, and volume time series (`eda.json`).
4. **Zero-Leakage Feature Extraction**: Fits TF-IDF and StandardScaler strictly on the training partition (`feature_pipeline.joblib`).
5. **Model Training & Tuning**: 5 classifiers (Logistic Regression, Naive Bayes, Random Forest, LightGBM, XGBoost) tuned via 5-Fold Stratified Cross-Validation (`best_model.joblib`).
6. **Model Evaluation & Error Mining**: Generates ROC curves, confusion matrices, and extracts false positives, false negatives, and low-confidence cases (`results.json`, `errors.json`).
7. **SHAP Global Explainability**: TreeSHAP feature attribution ranking across textual, behavioral, and temporal domains (`shap_global.json`).
8. **Pattern Mining & Syndicate Profiling**: Discretizes transactions, mines association rules with mlxtend (lift > 1.2), and profiles top suspicious reviewers (`patterns.json`, `reviewers.json`).

---

## 5. Architectural Principles & Rules

1. **Zero Data Leakage**: Transformers and statistics are fitted strictly on the train partition. Validation and test sets are strictly transformed.
2. **Determinism**: Fixed random seed (`RANDOM_STATE = 42`) across all ML modules.
3. **Artifact-Only API**: Fast in-memory startup via `ArtifactManager` with graceful HTTP 503 fallback if artifacts are missing.
4. **Mandatory Disclaimer**: All predictions include:
   > *"Preliminary analytical result. Does not replace human verification or platform-level moderation."*
